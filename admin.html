SETUP REQUIRED

连接内容数据库

请先在 site-config.js 中填写 Supabase Project URL 和 Publishable key，并运行仓库中的 supabase/schema.sql。

ADMIN ACCESS

管理员登录

登录后可以修改成员资料、上传图片并发布公告。

CONTENT MANAGER

网站管理

原始页面内容保留在仓库中；这里保存的是管理员确认后的更新。

成员信息

选择成员即可快速修改；关闭“公开显示”会隐藏成员，但不会删除原始资料。

公告

草稿不会显示在公开网站；发布后的公告将出现在 News 页面顶部。
